# Literature annex — verified 2025–26 sources behind spec/14 §7–§8

**Status: reference (not a spec).** Sweep run 2026-08-22 by eight parallel finders (≥10 distinct queries each) with one adversarial citation verifier per finder and a coverage critic; ~170 raw findings, deduplicated and pruned here to the ones that carry a *mechanism* ACE can borrow. Scope note on the request wording: "IML" was read both ways — **ICML 2026** (July 2026; ICML/ICLR/NeurIPS items below) and **Interactive Machine Learning** (mixed-initiative / human-in-the-loop; IUI/CHI/UIST items below). KDD 2026 (Jeju, 9–13 Aug 2026) is covered via arXiv acceptances, Amazon Science's KDD-2026 page and the workshop accepted-paper lists; OpenReview and the ACM DL were behind browser-verification / 403 walls for every agent, so KDD research-track *texts* were not opened — entries marked **?** are title-level only.

Verification marks: **✔** title/venue/year/claim confirmed on the page by a second agent (all ten KDD/WWW-2026 items were so confirmed, SOP-Bench included) · **✔c** confirmed with a citation correction applied here · **◦** finder opened the arXiv/venue page; not independently re-verified · **?** unverifiable or title-only. Venue strings follow the arXiv comments line unless a proceedings page was opened. Read every entry as "what to borrow + where it does not transfer"; numbers are the papers' own.
